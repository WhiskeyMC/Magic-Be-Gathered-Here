## 🃏 Deck File Types

I may post decks as:

* `.txt` decklists
* `.csv` card lists
* `.pdf` visual deck sheets
* Image previews
* Zipped deck folders

Basically, whatever makes the deck easiest to look at, download, and send around.

## 🧭 How to Use the Cabinet

Pick a deck, open its folder, and grab whatever file is easiest to use.

Each deck may have:

* A simple text decklist
* A visual PDF or image sheet
* A preview image
* A link to the full online deck
* Notes about the deck’s theme or playstyle
